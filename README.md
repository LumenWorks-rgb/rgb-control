# RGB Control

[English](README.en.md) · **Русский**

Лёгкая программа для Windows: подсветка вентиляторов, клавиатуры, мыши, видеокарты и оперативной памяти, кривые вентиляторов и помпы, обработка микрофона — всё в одном небольшом окне.

**[⬇ Скачать последнюю версию](../../releases/latest)** — файл `RGB Control Setup X.Y.exe`

![RGB Control — главное окно](docs/screenshot-main.png)

---

## Что умеет

- **Подсветка** — эффекты (радуга, волна, дыхание, огонь, метеоры и др.), свои цвета, синхронизация всех устройств в такт. Вентиляторы на материнской плате можно разметить по одному. У клавиатур — встроенные эффекты прошивки и кнопка «Выключить подсветку»; клавиатуры можно переподключать на ходу.
- **Охлаждение** — кривые вентиляторов и помпы по температуре, фиксированная скорость или «как в BIOS». Вентиляторы видеокарты NVIDIA тоже настраиваются. Режим «Тихая кривая» — одной кнопкой вентиляторы корпуса, процессора и видеокарты становятся заметно тише, а при нагреве плавно прибавляют. При перегреве вентиляторы сами уходят на 100%.
- **Звук** — обработка микрофона как в OBS: шумоподавление нейросетью RNNoise, шумовой гейт, эквалайзер, компрессор, лимитер. Обработанный голос можно отдавать в Discord и игры через VB-Audio Virtual Cable.
- **Подготовка** — при первом запуске программа сама проверяет компьютер по каталогу из ~2500 RGB-устройств и показывает, чем управляет, а что пока не поддерживается.
- **Не мешает играм** — почти не нагружает компьютер; в трее, автозапуск вместе с Windows.

### 🟡 По описанию, без проверки

Должно работать, но на живом железе ещё не проверялось:

- **Материнские платы ASUS** с контроллером Aura USB (поколение X570/B550 и новее: ROG, TUF, Prime, Strix) — с версии 2.8. Armoury Crate должен быть закрыт.
- **Мыши Attack Shark** X6, R1, X3, X3 Pro, X3 Max, X8 Plus — с версии 2.8. Модель определяется сама (или выбирается вручную); пока она не известна, DPI не меняется.
- **Клавиатуры Cidoo** на QMK/VIA: QK61, QK61 V2, V21, V33, V65 Pro, V68, V75, V75 Plus, V87, ABM066, ABM098, Stellar, Nebula — с версии 2.8. Встроенные эффекты клавиатуры, цвет, яркость и скорость; способ управления и список эффектов программа определяет сама.
- **FIFINE** — микрофоны, гарнитуры и микшеры на том же протоколе, что AM9, и стойки для наушников с подсветкой — с версии 2.8.
- **Видеокарты Palit / PNY / Gainward** других моделей с тем же контроллером подсветки — с версии 2.8.
- **Любые клавиатуры на QMK/VIA** — Keychron, GMMK, Akko и другие с поддержкой VIA: эффекты, цвет, яркость и скорость. Названия эффектов — из базы описаний VIA (Keychron и ещё почти 200 моделей со своим набором эффектов); у остальных — стандартный список QMK или эффекты по номерам.
- **ОЗУ** на других контроллерах ENE — ASUS, G.Skill Trident Z, TeamGroup T-Force, Patriot Viper и др.
- **Видеокарты** MSI RTX 40/50 других серий.
- **Охлаждение** на других платах, которые видит LibreHardwareMonitor.

Если у вас такое железо — проверьте и напишите, получилось ли. Это очень помогает.

### ❌ Пока не поддерживается

Платы MSI / Gigabyte, старые платы ASUS (X470 и раньше), видеокарты других производителей, ОЗУ Corsair и Kingston Fury, периферия Razer / Logitech / SteelSeries и многое другое. Поддержка добавляется по отчётам — см. ниже.

**Клавиатуры Ajazz на чипах Sonix и Sinowealth** (AK980, AK870, AK820 MAX, AK820 PRO и др.) и **мыши Ajazz** программа уже узнаёт, но пока не управляет ими. Если у вас такая — нажмите в окне «Комплектующие» **«Хочу поддержку — отправить отчёт»**: по нему поддержка добавляется быстро.

## Установка

1. Скачайте `RGB Control Setup X.Y.exe` из [Releases](../../releases/latest) и запустите.
2. Windows может показать синее окно «Windows защитила ваш компьютер» — у установщика пока нет цифровой подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Программа ставится для текущего пользователя, права администратора для этого не нужны. По желанию установщик:
   - ставит драйвер **PawnIO** — нужен для вентиляторов, помпы и подсветки ОЗУ;
   - включает **«Всегда запускать с правами администратора»** — охлаждение и ОЗУ работают только с ними; Windows спросит разрешение один раз.
4. Новые версии ставятся поверх, настройки сохраняются. Удаление — в «Параметры → Приложения».

**Требования:** Windows 10 или 11 (64-бит). Для отправки обработанного голоса в другие программы — бесплатный [VB-Audio Virtual Cable](https://vb-audio.com/Cable/).

## Если что-то не работает

Проще всего — прямо из программы:

- на экране устройства кнопка **«Не работает?»**, или в настройках (⚙) — **«Сообщить о проблеме»**: опишите в двух словах, что не так, и нажмите «Отправить». Автору уйдут ваш текст, сведения о железе и журнал ошибок. Личные данные не отправляются; всё, что уйдёт, можно посмотреть кнопкой «Что будет отправлено».

Или через GitHub: **[Issues → New issue](../../issues/new/choose)** и приложите файл из настроек → **«Сохранить отчёт совместимости»** (появится на рабочем столе).

Хотите поддержку своего устройства — тоже пришлите отчёт: по нему видно, как устройство устроено.

## Безопасность

- Программа не трогает ничего, кроме подсветки и вентиляторов. В память SPD планок и в настройки BIOS она не пишет никогда.
- Незнакомым устройствам команды не отправляются: только чтение того, что они сами сообщают о себе.
- При выходе устройства возвращаются к своим собственным эффектам, а вентиляторы — к управлению BIOS. Даже если программа аварийно закрывается из-за ошибки, вентиляторы сначала отдаются BIOS.

**RGB Control** is a lightweight Windows app for RGB lighting (fans, keyboard, mouse, GPU, RAM), fan/pump curves and microphone processing — all in one small tray app. Full English description: [README.en.md](README.en.md).
