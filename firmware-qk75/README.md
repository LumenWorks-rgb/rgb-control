# Прошивка Cidoo QK75 для RGB Control

Прошивка на основе QMK для клавиатуры **Cidoo QK75** с поклавишной подсветкой: RGB Control может красить каждую клавишу отдельно и показывать свои эффекты. Готовый файл прошивки входит в установку RGB Control (папка «Прошивка Cidoo QK75»); здесь — её полные исходники.

Лицензия: **GNU GPL v2** (как у QMK), текст — [LICENSE-GPLv2.md](LICENSE-GPLv2.md).

> [!WARNING]
> **Прошивка на ваш страх и риск.**
> - Это неофициальная прошивка: Cidoo её не выпускала и не поддерживает, прошивка может лишить клавиатуру гарантии.
> - LumenWorks не несёт ответственности за клавиатуру. Ошибка (не та модель, отключение кабеля во время прошивки) может сделать её неработоспособной.
> - **Заводская прошивка в комплект не входит.** Без неё вернуть клавиатуру к заводскому состоянию нельзя. Если не уверены — не прошивайте, пока не получите заводскую прошивку у поддержки Cidoo или продавца.
> - Всё остальное в RGB Control работает и без этой прошивки — она нужна только для поклавишной подсветки.

## Откуда

- Основа: форк QMK [aliveoutside/qmk_firmware](https://github.com/aliveoutside/qmk_firmware), ветка `qk61`, коммит `108f228b0da23e91a53b2697ad602c035f2cd192` (поддержка микроконтроллера ES32 FS026 и клавиатуры Cidoo QK61).
- Для QK75 переделаны раскладка матрицы и карта светодиодов (82 светодиода; данные взяты из заводской прошивки Cidoo QK75 V0100) и добавлена команда поклавишных цветов.

## Что добавлено

Поклавишные цвета — через VIA-канал (Raw HID):

```
07 10 <первый светодиод> <сколько, до 9> R G B R G B ...   — задать цвета подряд
08 10                                                     — в ответе data[2] = число светодиодов (82)
```

## Сборка

1. Подготовьте окружение QMK ([инструкция](https://docs.qmk.fm/newbs_getting_started)) и склонируйте форк:
   ```
   git clone -b qk61 https://github.com/aliveoutside/qmk_firmware.git
   cd qmk_firmware
   git checkout 108f228b0da23e91a53b2697ad602c035f2cd192
   git submodule update --init --recursive
   ```
2. Скопируйте папку `keyboards/qk75` отсюда в `qmk_firmware/keyboards/qk75`.
3. Соберите:
   ```
   make qk75:default
   ```
   Получится `qk75_default.bin`.

## Прошивка

1. Отключите кабель клавиатуры.
2. Зажмите **Esc** и вставьте кабель — появится диск.
3. Скопируйте на него `.bin`. Клавиатура перезагрузится сама.

Вернуть заводскую прошивку можно так же — файлом заводской прошивки Cidoo. Мы её не распространяем (это закрытая прошивка производителя): запросите её у поддержки Cidoo через форму на [cidootech.com](https://cidootech.com) или у продавца.

> Перед прошивкой проверьте, что у вас именно **QK75** (утилита «Проверить QK75» в папке прошивки в составе RGB Control). Прошивка от другой модели может сделать клавиатуру неработоспособной до перепрошивки.
